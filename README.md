# Chat Vocal Simple (Frontend)

Interface web simple en React :
- Connexion par pseudo
- Grand bouton rond pour entrer en chat vocal
- Choix de 14 régions ou **France entière**
- Écran d'appel avec 3 boutons :
  - **Zapper** (passer à la personne suivante)
  - **Couper/activer micro**
  - **Couper/activer haut-parleur**

## Démarrage local

```bash
npm install
npm run dev
```

Ouvre ensuite : http://localhost:5173

## Build production

```bash
npm run build
```

Le dossier généré est `dist/`.
